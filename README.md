## Run locally

This is a static website. No package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Jithendra54/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension or Python:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Deployment

The site is intended for static hosting with GitHub Pages.

1. Push the website files to the `main` branch.
2. Open the repository's **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and the repository root (`/`), then save.
5. Wait for the GitHub Pages deployment to complete.
